# agent (Integrator)
`agent.py`: investigation loop behind `LLMProvider.chat` (Databricks endpoint via `DATABRICKS_MODEL_ENDPOINT`, or `LLM_API_KEY` -> `claude-opus-5-5`; none -> scripted). Caps: 8 tool calls, 60 s. `tools.py`: the 8 tools in `contracts/agent_tools.json`, calling backend services directly; replan only with permitted reason codes, never applies. `explain.py`: deterministic fallback explanation (Observation / Uncertainty / Planning reason / Action/status) + grounding check (every number/time must come from tool output or the diff; failures fall back). `run_chat` answers from saved decisions.
