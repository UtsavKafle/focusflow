# scheduler (Integrator)
Pure Python, deterministic. `optimize.py`: greedy (deadline, -priority, task_id), earliest-first into allowed - fixed - protected sleep - locked; keeps still-valid blocks, re-places displaced study; split/min block/max continuous/breaks; never before now. Rest protection (SUSTAINED_LOAD / LIMITED_ESTIMATED_REST) adds a `sleep_extension` toward target sleep and no more study tonight. Leftover -> `unscheduled_work` (partial). Always validated with `validate.py`. Golden tests: `tests/test_scheduler_golden.py`.
